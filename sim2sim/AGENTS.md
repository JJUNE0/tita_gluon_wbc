# sim2sim 최소 코드 정책

루트 AGENTS.md의 실행 도메인·검증·실험 기록 규칙을 함께 따른다.

- 현재 TITA PPO·FlashSAC 재생과 read-only real2sim에 필요한 코드만 유지한다.
- 학습된 observation/action 순서·scale의 기준은 저장된 체크포인트 설정이다. 실행기와 YAML에 같은 값을 중복 선언하지 않는다.
- 사용하지 않는 함수, 빈 호환용 API, 중복 검증, 실행 래퍼를 남기지 않는다.
- 한 가지 기능을 위해 별도 파일·클래스·스레드를 추가하기 전에 기존 실행 흐름으로 처리할 수 있는지 확인한다.
- 코드 축약보다 명확한 변수명과 직선적인 제어 흐름을 우선한다. 긴 삼항식, 중첩 조건, 한 줄에 여러 동작을 넣는 표현은 피한다.
- 실제로 필요한 형상·유한값 검사, 체크포인트 검증, viewer 종료, 실험 증거 기록은 유지한다.
- 다른 학습 코드에서 쓰는 URDF/mesh 자산은 실행 코드 정리와 구분한다. 임시·검증 코드는 test/에 작성한다.
